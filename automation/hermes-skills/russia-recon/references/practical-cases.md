## 案例 1: РОСНА Инжиниринг (rosna-spb.ru) — 2026-05-14

- **OKVED**: 28.xx（通用机械制造）→ P0

### 亮点
1. **联系人金矿**: 官网 Контакты 页直接列出了 3 位高管 + 个人邮箱 + 分机号
   - 技术总监: Альтшулер В.И. vladimir.altshuler@rosna-spb.ru

## 案例 3: НЭК (Невские Электронные Компоненты / necspb.com) — 2026-05-14

### 公司画像
- **类型**: 圣彼得堡电子元器件分销商（纯贸易），28年历史
- **来源**: `necspb.yp.ru`（yp.ru 黄页子域名）
- **规模**: 50,000+ SKU，B2B only（仅法人客户）
- **品牌库**: Analog Devices, TI, ST, Infineon, Microchip, Broadcom, ON Semi, Altera, Mean Well, WAGO 等 30+ 品牌

### 亮点
1. **KillBot 旁路方法**: yp.ru 被 KillBot 完全阻断，用 DuckDuckGo Lite 搜索 `[子域名前缀] компания` 直接找到公司真实官网
2. **纯分销商正确终止**: Step 0 6维度判定 → ❌ 纯分销商，按规则跳过 Step 1-7，未浪费时间
3. **INN 直接从官网 footer 提取**: ООО «Невские электронные компоненты» ИНН 7810111382 — 无需 rusprofile
4. **Lightpanda 在 necspb.com 工作正常**: 官网为 Bitrix CMS，非 SPA，Lightpanda 完美抓取

### 坑点
1. **network-sentinel preflight timeout (exit 124)**: `check --timeout 15` 超时 → 直接跳过预检，进入实际抓取
2. **yp.ru (KillBot) 和 Yandex (smartcaptcha) 双双被拦**: 两个入口都走不通
3. **DuckDuckGo 主站 (html.duckduckgo.com) 空结果**: 但轻量版 `lite.duckduckgo.com` 完全可用
4. **SearXNG MCP 也失败**: JSON 解析错误，不可靠

### Step 0 判定路径
1. 访问 yp.ru → KillBot 拦截
2. DuckDuckGo Lite 搜索 `necspb компания` → 找到 necspb.com
3. Lightpanda 抓取 necspb.com → 获取全部信息（30+品牌、INN、邮箱、电话）
4. 6维度判定：产品所有权❌ | 技术文档❌ | 地址办公室❌ | 无认证❌ → **纯分销商**
5. **终止全流程**

### 外联建议
- 可作为竞争对手观察，非目标客户
- 留意其采购的中国品牌（Mean Well, Mornsun, ElecSuper, JSMSEMI, UMW, GAINTA 等）

## 案例 4: Астро Пенза (astropenza.ru) — 2026-05-20

### 公司画像
- **类型**: 奔萨汽车电子制造商，自有品牌"Астро"，1992年建厂
- **规模**: 25人，营收5500万卢布/年(↓13%)，小企业
- **OKVED**: 29.31（汽车电子设备生产）→ P0
- **产品线**: 控制器/继电器/传感器/调节器/电压转换器/照明模块 30+ 品类
- **SMD产线**: Assembleon Opal X II 贴片机 + 0.5-25吨冲压车间

### 亮点
1. **采购直拨公开标注**: 官网 Контакты 页直接列出「Снабжение +7(8412)48-00-15」— 6个部门电话全部公开
2. **CEO+会计双源确认**: Старцев В.В. (CEO+100%股东) + Мешалкина М.А. (总会计师) — rusprofile + 官网交叉验证
3. **银行账户公开**: 官网直接列出 Альфа-Банк 结算账户/BIK — 对后续交易谈判有用
4. **制裁全绿零翻车**: OFAC/EU/UK 五源零命中，纯商业小企业，无合规顾虑
5. **对外寻找经销商姿态**: productcenter.ru 标注"ищем дилеров" — 向外看，适合主动外联

### 坑点
1. **api-registry 噪声**: 搜「Астро Пенза」返回6个莫斯科无关实体（АСТРО ТОО, ИЧП АСТРО等），公司名太通用 → 必须加城市限定
2. **VK captcha 未升级**: browser-fetch 被 VK captcha 拦截后直接标记 blocked，**应按规则先升级 stealth-fetch 再放弃**
3. **contacts 页不在主域名根路径**: `/kontakty.html` 而非标准 `/contacts/`，fetch 用 `http://` 协议成功，`https://` 也可
4. **hh.ru API 403**: 匿名访问被拒，需 HH_ACCESS_TOKEN

### 抓取细节
- rusprofile 搜索「ООО+Компания+Астро+Пенза」→ **自动跳转** id/10863149，无需手动翻页
- CloakBrowser 后端: transport=cloakbrowser, 21.5s 拿首页, 12.5s 拿 rusprofile
- VK blocked_sources 记录: vk.com → captcha (未升级 stealth-fetch 即放弃，下不为例)

### 评分分析
- 采购需求(海关实证): 0 — Comtrade key 未配置
- 采购需求(产品推断): 15 — 控制器/SMD产线/传感器/继电器 → MCU+功率+被动元件
- 客户类型: 20 — 自有品牌+自有工厂+专利+商标
- 联系信息: 20 — CEO姓名+采购直拨+邮箱
- **总分: 55/100 ⭐⭐⭐**（配好 Comtrade key 可达 95）

### 外联策略
- **推荐联系人**: 采购部直拨 +7(8412)48-00-15 或 CEO Старцев В.В.
- **切入角度**: SMD产线(Assembleon)消费MCU/IC → 华强北现货供应 + 控制器/继电器元器件配套
- **俄语开场句**: "Здравствуйте! Увидели, что ваша компания производит автомобильную электронику на собственном заводе и предлагает услуги SMD-монтажа. Мы поставляем электронные компоненты..."

### 通用经验

#### api-registry 对通用名词的噪声问题
当公司名是简短通用俄语词（如 Астро, Спектр, Импульс, Диапазон）时：
1. `api-registry` 会返回大量同名无关实体（多为莫斯科历史注册）
2. **正确做法**: 直接 rusprofile 搜索「ООО+全称+城市名」，自动跳转目标
3. 不依赖 `api-registry` 返回的第一条；先查官网地址/城市 → 用城市交叉匹配

#### VK captcha 升级顺序（自查坑点）
1. browser-fetch（首选，cloakbrowser 后端）→ captcha
2. **stealth-fetch**（升级）→ 再试一次 ← 本案例**漏掉了这一步**
3. 仍然 captcha → blocked_sources 记录，转替代源

## 通用经验

| 场景 | 成功率 | 最佳路径 |
|------|:-----:|---------|
| 官网直接列高管+邮箱 | ✅ 高 | 访问 /kontakty/ 或 /contacts/ |
| 官网仅 info@ | ⚠️ 中 | 查 /requisites/ 或 /about/ → 可能隐藏 buh@ / support@ |
| rusprofile 触发 CAPTCHA | ⚠️ 中 | 官网 Реквизиты / Контакты 页直接提取 INN/OGRN |
| Yandex 搜索触发 CAPTCHA | ❌ 低 | 直接访问目标平台（vk.com/company/... / hh.ru/employer/...） |
| OpenSanctions INN 查询 404 | ⚠️ 中 | 弹性的：`ru-inn` 捷径 URL 不一定有数据，换搜索页面 |
| SPA 官网产品页 | ⚠️ 中 | browser_navigate 点击导航，而非直接 URL |
