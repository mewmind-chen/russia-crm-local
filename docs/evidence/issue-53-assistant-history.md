# Issue #53 AI 助手会话历史验收

日期：2026-07-25

## 交付范围

- 新增服务端 AI 会话、消息和滚动摘要持久化。
- 新对话不删除旧会话；历史详情只读数据库，不触发模型。
- 聊天只向模型提供滚动摘要、最近 6 条消息和当前问题。
- 保存原问题、原回答、来源、关联客户、结果集、模型、引擎、usage、成本和时间。
- 同引擎继续使用服务端保存的原生 session ID；切换引擎时清空外来原生会话并保留摘要。
- 支持重命名、收藏、归档和恢复，不提供永久删除。
- 工作台本地存储只保留当前会话指针和 scope，不保存正文。

## 权限与审计

- 销售只能读取自己的会话。
- 经理可读取自己的会话和销售会话，不能读取其他经理或管理员会话。
- 管理员可读取全部会话。
- 经理对员工会话只读；本人和管理员可重命名、收藏、归档和恢复。
- 跨用户查看以及重命名、收藏、归档、恢复写入 `crm_audit_log`。
- 未知会话返回 404，已存在但越权的会话返回 403。
