# Phase C/E 目标：所有列表页用户级列布局与排序

日期：2026-09-01

## 目标

将“用户可自由选择列表列内容、列顺序和排序方式”从客户列表扩展为所有业务列表页的统一目标。

覆盖客户、线索池、管道、告警、洞察、回收站、主管任务/风险/指标、通知，以及后续纳入统一壳的联系人和 Recon 等表格/列表结果页。

## 目标行为

- 每个用户可在服务端有效字段 schema 的范围内选择显示/隐藏列。
- 每个用户可调整列顺序并保存自己的布局偏好；可存在角色默认值，但不能扩大权限。
- 每个用户可选择授权排序字段、升序/降序，必要时支持多级排序；服务端使用白名单字段和稳定 tie-breaker。
- 布局偏好只影响呈现和排序，不改变数据范围、筛选授权、导出权限或业务动作权限。

## 当前状态

- 目前客户列表及其他列表仍有页面级固定列或独立排序实现，统一 List widget 尚未落地。
- 已有字段目录、有效 schema、白名单投影和 widget 注册表基础，可作为该目标的实现基础。
- 当前不修改业务代码，不修改生产，不触碰冻结历史计划。
